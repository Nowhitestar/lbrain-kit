# Write Cases

## Should trigger

- “用我的研究和写作风格起草一篇文章。” → retrieve narrow context and create a private traceable draft.
- “Adapt this draft for a trusted newsletter audience.” → preserve sources and keep visibility separate from publication.

## Should not trigger

- “Summarize these Sources into my Wiki.” → use `lbrain-weave`.
- “What did I write about agents?” → use `lbrain-retrieve`.

## Publication case

- The user approves the final text but not sending it → keep it a draft; do not publish or add `published_url`.
