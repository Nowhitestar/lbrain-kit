# Personal Skills

User-owned and imported third-party skills live here. Start private in `lbrain.json`, validate test cases, then mark active. Keep `SKILL.md` portable with only `name` and `description` frontmatter. Public and published are different states: only the user may approve either. A distributable Skill declares its license in `lbrain.json` and includes the matching `LICENSE` or `LICENSE.md` file.
