# Capture Bundles

All external originals land here before processing. A Capture Bundle consists of one human-readable Markdown note and its versioned files under `_assets/<capture_id>/`.

- Read and annotate the original here before weaving it.
- Identical recaptures are no-ops; changed originals create immutable versions.
- A partial capture keeps the available text, origin, media manifest, and retry state.
- Do not move one file by hand. Use the Weave operation so the note, assets, links, and state move together.
