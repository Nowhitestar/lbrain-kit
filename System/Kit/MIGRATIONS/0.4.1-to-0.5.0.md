# Migration: 0.4.1 to 0.5.0

This feature release adds optional developer-mode browser Capture and atomic Inbox-to-Source Weave. It does not rewrite existing Projects, Sources, Wiki, Personal Skills, Identity, Outputs, or Captures.

## Affected ownership

- **Kit-owned:** Capture and Weave Skill packages, Inbox/Source contracts, Git LFS rules, Tracer, tests, setup, and release metadata.
- **Seeded:** no required content rewrite. Preserve personalized Seeded files exactly.
- **User-owned:** no automatic changes. Existing Inbox items remain where they are until the user explicitly weaves them.

## Preconditions

1. Commit or back up personal changes and confirm the selected release is exactly `v0.5.0`.
2. Confirm Git LFS is installed before capturing binary media.
3. If enabling the browser surface, use Chrome developer mode and select the intended LBrain/Obsidian Vault root. Chrome Web Store installation is not part of this release.

## Upgrade

Follow `System/Kit/SETUP.md` and merge only `v0.5.0` into personal `main`. No bulk migration runs. Existing Capture notes continue to validate; new browser originals enter `Inbox/Captures` and move only through an explicit Weave transaction.

Copy-installed Agent runtimes should refresh `lbrain-capture` 0.5.0 and `lbrain-weave` 0.3.0 after the merge. Symlink runtimes follow the canonical packages automatically. Native Host registration is optional and local to the selected Chrome profile and Vault.

## Validation

Run:

```sh
python3 System/Kit/check.py
python3 System/Kit/Examples/Tracer/run.py
git diff --cached --check
git diff --cached --name-status
```

If browser Capture is enabled, reload the unpacked extension, cancel one preview to prove zero side effects, then confirm one non-sensitive generic page. Verify its HTML snapshot opens from Obsidian and that Downloads remains untouched before explicitly weaving it.

## Rollback

Abort an uncommitted upgrade when validation fails. After a committed local upgrade, revert only the upgrade merge commit. Unregistering the optional Native Host does not delete the selected Vault or its staging directory. Do not delete User-owned Inbox, Source, Wiki, or asset content during rollback.
