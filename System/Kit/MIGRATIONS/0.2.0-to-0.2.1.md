# 0.2.0 to 0.2.1

This patch preserves imported Source bodies during validation and ignores local runtime-state directories. It changes no Seeded or User-owned content and requires no manual reconciliation.

## Upgrade

Follow the standard tagged-release workflow in [[System/Kit/SETUP]] and merge `v0.2.1` into personal `main`.

## Validation

```sh
python3 System/Kit/check.py
python3 -m unittest discover -s System/Kit/tests -v
```

The validator must report zero errors. Existing Sources, Wiki notes, Personal Skills, Context Packs, and personalized Seeded files must remain unchanged.

## Rollback

Revert the upgrade merge with `git revert -m 1 <upgrade-merge-commit>`. Do not rewrite shared personal history.
