# Migration: 0.4.0 to 0.4.1

This required patch updates the shared disclosure validator so safe static pagination code in public Personal Skills does not block a Kit upgrade. It does not change Personal Skill packages or personal content.

## Affected ownership

- **Kit-owned:** `System/Kit/` receives the validator, regression tests, release metadata, and documentation patch.
- **Seeded:** no change. Preserve personalized Seeded files exactly.
- **User-owned:** no change. Existing Projects, Knowledge, Sources, Proposals, Outputs, Personal Skills, Context Packs, and runtime state are preserved.

## Preconditions

1. Commit or back up all personal changes.
2. Read `System/Kit/CHANGELOG.md` and confirm the selected release is exactly `v0.4.1`.
3. Confirm the current checkout contains no unresolved merge or rebase.

## Upgrade

Follow `System/Kit/SETUP.md` and merge only the `v0.4.1` tag into personal `main`. The tag contains the complete v0.4.0 feature release plus this compatibility patch, so upgrading directly from v0.3.0 or v0.4.0 is supported.

No Skill package reinstall is required solely for this patch. Copy-installed runtimes still need the normal explicit refresh when their Skill package version changes.

## Validation

Run:

```sh
python3 System/Kit/check.py
python3 System/Kit/Examples/Tracer/run.py
git diff --cached --check
git diff --cached --name-status
```

Before committing the merge, confirm the staged paths do not replace any Seeded or User-owned content.

## Rollback

If validation fails, abort the uncommitted merge. If the merge was already committed locally, revert only that upgrade merge commit. Do not delete or regenerate User-owned directories.
