# 0.2.3 to 0.2.4

This patch makes scheduled Context Intake auditable and decision-complete. A newly configured Project now establishes a historical baseline and a compact `Intake Profile` before relying on incremental scans. Intake distinguishes source discovery from full reading, preserves available reasoning and supersession, and reports coverage at the source and anchor level.

Existing personal content is not moved. For each already scheduled Project, review its Project note and add an `Intake Profile` with domains, enabled sources, stable anchors, source precedence, baseline status, and last completeness review. Treat an earlier recent-window-only scan as `baseline_pending` until a reviewed historical backfill is complete.

Follow the standard tagged-release workflow in [[System/Kit/SETUP]] and merge `v0.2.4` into personal `main`.
