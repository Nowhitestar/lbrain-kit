# Personal Intelligence Tracer

`run.py` creates a temporary LBrain and exercises the three Intelligence Pipelines through their real Atomic Operation entrypoints: Project Setup, partial and complete Context Intake, a framed browser Native Messaging capture into Inbox, an Obsidian-openable receipt, atomic Bundle/asset promotion through `weave.preview` and `weave.apply`, source-grounded Wiki creation, Skill Improvement Proposal, immutable Change Preview, approved Skill application, runtime refresh, retrieval, and idempotent rerun. It deletes the temporary copy when finished and never writes to the active LBrain.

Run from the repository root:

```sh
python3 System/Kit/Examples/Tracer/run.py
```

Expected final line: `PERSONAL INTELLIGENCE TRACE PASS`.
