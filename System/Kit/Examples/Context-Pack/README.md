# Context Pack Tracer

`run.py` exercises a completely synthetic, network-free Context Pack lifecycle:

1. route durable items from Git, Notion, Zulip, and Gmail into an isolated LBrain;
2. preview and build a public AgentKey Candidate with one portable Skill;
3. publish it to a temporary local bare Git repository and mount its Submodule;
4. copy the Pack without Git metadata; and
5. verify that a recipient can use the portable Pack without the source LBrain.

No real connector, personal content, remote repository, or network request is used.
