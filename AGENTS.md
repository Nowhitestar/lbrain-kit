# Agent Operating Contract

Treat this repository as the user's private second brain and canonical personal context.

1. Read the nearest directory `README.md` before changing content.
2. Follow [[System/Rules/Core/agent-permissions]] and [[System/Kit/OWNERSHIP]].
3. Prefer Wikilinks without `.md`; use a path only when names collide.
4. Keep raw claims in Sources and synthesis in Wiki. Do not present dated context as a current external fact without live verification.
5. Default new content to `visibility: private`.
6. Never directly change Identity, core rules, Kit-owned files, publication state, or archive state when the permission contract requires a proposal.
7. Do not hard-delete by default. Propose archival instead.
8. Validate authorized changes with `python3 System/Kit/check.py` before committing.
9. Commit validated, authorized changes locally using the prefixes in [[System/Rules/Core/git-workflow]]. Do not push unless explicitly asked.
