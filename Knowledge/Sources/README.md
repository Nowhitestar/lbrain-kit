# Sources

Store promoted durable originals. External material first enters Inbox as a Capture Bundle; a user-triggered Weave promotes the original and its assets here after synthesis or an explicit `skip` decision. Preserve the author's meaning and provenance; do not silently rewrite raw excerpts. Use `capture: reference`, `excerpt`, or `full`, and set `weaving` to `pending`, `woven`, or `skip`.

Agents may create Sources for internally generated evidence and repair metadata directly. Material changes to captured source text require explicit approval.
